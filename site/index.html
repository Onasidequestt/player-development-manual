Players Manual is a performance system for athletes: a daily journal, readiness and practice tracking, game logs and long-term goals, tailored to each sport. The hockey version comes first.

Sign in or get the appSee what is inside

One system, built around the athlete

The hockey version is the working model. These are the parts it already has.

Daily check

A short readiness check-in, then habits and the day's block, so the athlete starts from how they actually feel.

Practice and game logs

Write down what happened while it is fresh, with game numbers that can be tracked over a season.

Ratings over time

Self-ratings across the areas of the game, shown as then-versus-now so progress is visible.

Journal and manual

Identity, standards and long-term vision written in the athlete's own words and shown again each day.

Hockey first, then every sport

Each sport gets its own version: its own positions, skills, logs and language, on the same foundation. We finish one before starting the next.
